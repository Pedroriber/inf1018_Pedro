int main() {

- mas dava segmentation default, isso ocorreu pois call e8 só aceita um deslocamento de 32 bits,
 mas o offset entre o codigo e add era muito grande, +2gb.
 A solução foi usar um registrador pra colocar o endereço de add e fazer a chamada desse registrador,
 o que deturpa um pouco do objeto do laboratório
 int main() {

    unsigned char codigo[] = {
        0x48, 0xB8,                    /* movabs ..., %rax */
        0,0,0,0,0,0,0,0,              /* endereço de add */
        0xFF, 0xD0,                    /* call *%rax */
        0xC3                           /* ret */
    };

    unsigned long endereco = (unsigned long)add;
