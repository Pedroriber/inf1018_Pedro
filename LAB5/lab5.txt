3. Qual o tamanho, e como os tipos abaixo são organizados na memória?

a. struct X1 {
  char c1;
  int i;
  char c2;
};
R: c1000 iiii c2 c1 .... (tam= 9 bytes) 
Correcção: 12 bytes ->  c1000 iiii c2000 (O tamanho final é múltiplo do maior alinhamento)

b. struct X2 {
  long l;
  char c;
} x2 = {0x0102030405060708, 0xc1};
R: 8+1+7(padding)= 16 bytes

c.struct X3 {
  int i;
  char c1;
  char c2;
} x3 = {0x01020304, 0xc1, 0xc2};
R: 4+1+1+2(padding)=8 

d. struct X4 {
  struct X2 x;
  char c;
} x4 = {{0x0102030405060708, 0xc1}, 0xc2};
R: 16 + 1+15(padding)=32 
Correcção: tamanho final multiplo do long da struct X2, 24

e. struct X5 {
  char c1;
  char c2;
  char c3;
} x5 = {0xc1, 0xc2, 0xc3};
R: 1+1+1=3 bytes

f. struct X6 {
  short s1;
  int i;
  char c[3];
  short s2;
} x6 = {0x0102, 0x01020304, {0xc1, 0xc2, 0xc3}, 0x0102};
R: 2+ 2(padding)+4+3+1(padding)+2+2(padding)=16 bytes

g. union U1 {
  int i;
  char c[5];
};
R: iiiiiiii ou ccccc000

h.union U2 {
  short s;
  char c[5];
};
R: ss000 ou ccccc
Correcção: não é cinco pois deve der multiplo de 2(short)
então é 6 bytes
